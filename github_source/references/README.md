# Tài liệu tham khảo

Bản GitHub giữ nguồn và các manifest nhỏ trong thư mục này. Hai PDF gốc của người dùng và văn bản trích xuất **không nằm trong bản public**; xem [SOURCES.md](SOURCES.md) để mở paper tại trang chính thức. Nếu nhóm có quyền dùng bản PDF cục bộ, có thể đặt vào papers/ theo tên ghi trong manifest.

upstream/ là snapshot phục vụ đối chiếu nghiên cứu, không phải dependency chạy model. Code ACT được dùng nằm ở ../third_party/rh20t_act/; giữ license của source upstream. notes/ là nơi ghi thêm nhận xét và trang trích dẫn.

Không đưa dữ liệu RH20T, checkpoint hoặc nội dung làm việc riêng vào repository.
